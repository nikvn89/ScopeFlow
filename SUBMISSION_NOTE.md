# ScopeFlow V2 — Submission Note

## Title

ScopeFlow V2 — Self-Service AI-Governed Project Scope Control

## Note

ScopeFlow V2 lets any wallet create its own project, become that project’s Client, assign a Contractor, and lock a natural-language scope. Later change requests are classified by GenLayer consensus as SCOPE_IN, SCOPE_EXTENSION, or SCOPE_UNCLEAR. In-scope work proceeds without a new approval gate; scope extensions require both Client and Contractor approval before the active scope can change; unclear requests leave the scope unchanged. State is isolated by project_id, approvals are bound to the scope version they were classified against, and the deployer has no special project-owner privilege. The browser flow was verified end-to-end: self-service creation, SCOPE_IN, SCOPE_EXTENSION, Client approval, Contractor approval, and Scope V1→V2.
